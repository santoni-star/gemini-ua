# Gemini CLI (Українська версія)

![Gemini CLI Screenshot](./docs/assets/gemini-screenshot.png)

**Gemini CLI** — це ШІ-агент з відкритим вихідним кодом, який переносить потужність Gemini прямо у ваш термінал. Він забезпечує легкий доступ до моделей Gemini, надаючи найкоротший шлях від вашого запиту до результату.

Ця версія спеціально локалізована для українських розробників.

## 🚀 Чому Gemini CLI?

- **🎯 Безкоштовний рівень**: 60 запитів/хв та 1,000 запитів/день з особистим обліковим записом Google.
- **🧠 Потужні моделі Gemini 3**: Доступ до покращеного мислення та контекстного вікна в 1 млн токенів.
- **🔧 Вбудовані інструменти**: Пошук у Google, операції з файлами, команди оболонки, отримання даних з веб-сторінок.
- **🔌 Розширюваність**: Підтримка MCP (Model Context Protocol) для власних інтеграцій.
- **💻 Термінал-пріоритет**: Створено для розробників, які живуть у командному рядку.
- **🛡️ Відкритий код**: Ліцензія Apache 2.0.

## 📦 Встановлення (Українська версія)

Для користувачів Windows найпростіший спосіб — завантажити та запустити файл `install-ua.bat` з цього репозиторію.

### Швидке встановлення через NPM

```bash
# Встановити глобально
npm install -g santoni-star/gemini-ua
```

*Примітка: Через особливості збірки на Windows, якщо глобальне встановлення видає помилку, скористайтеся інструкцією нижче.*

### Встановлення з вихідного коду (найбільш надійно для Windows)

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/santoni-star/gemini-ua.git
   cd gemini-ua
   ```
2. Встановіть залежності та зберіть проект:
   ```bash
   npm install
   npm run bundle
   ```
3. Встановіть глобально:
   ```bash
   npm install -g .
   ```

## 🛠️ Використання

Запустіть CLI командою:
```bash
gemini-ua
```

### Основні команди:
- `/help` — показати довідку.
- `/settings` — відкрити налаштування.
- `/model` — змінити модель Gemini.
- `/clear` — очистити екран та історію.
- `/exit` — вийти з програми.
