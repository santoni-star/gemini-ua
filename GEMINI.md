# Контекст проекту Gemini CLI

Gemini CLI — це ШІ-агент з відкритим кодом, який переносить потужність Gemini прямо у термінал. Він створений як розширюваний та потужний інструмент для розробників.

## Огляд проекту

- **Мета:** Надати безшовний термінальний інтерфейс для моделей Gemini, що підтримує розуміння коду, генерацію, автоматизацію та інтеграцію через MCP (Model Context Protocol).
- **Основні технології:**
  - **Runtime:** Node.js (>=20.0.0)
  - **Мова:** TypeScript
  - **UI Framework:** React (використовується [Ink](https://github.com/vadimdemedes/ink) для рендерингу в CLI)
  - **Тестування:** Vitest
  - **Збірка:** esbuild
  - **Лінтування/Форматування:** ESLint, Prettier
- **Архітектура:** Монорепозиторій на основі npm workspaces.
  - `packages/cli`: Інтерфейс користувача, обробка вводу та рендеринг.
  - `packages/core`: Логіка бекенду, оркестрація Gemini API, побудова промптів та виконання інструментів.
  - `packages/core/src/tools/`: Вбудовані інструменти для файлової системи, оболонки та вебу.

## Збірка та запуск

- **Встановлення залежностей:** `npm install`
- **Збірка всього:** `npm run build:all`
- **Запуск у режимі розробки:** `npm run start`
- **Створення бандлу:** `npm run bundle`
- **Очищення:** `npm run clean`

## Конвенції розробки

- **Повідомлення комітів:** Дотримуйтесь стандарту [Conventional Commits](https://www.conventionalcommits.org/).
- **Стиль коду:** Дотримуйтесь існуючих шаблонів у `packages/cli` (React/Ink) та `packages/core` (Backend logic).
- **Ліцензійні заголовки:** Для всіх нових файлів вихідного коду включайте заголовок ліцензії Apache-2.0.
