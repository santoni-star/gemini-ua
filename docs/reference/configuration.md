# Конфігурація Gemini CLI

Gemini CLI пропонує кілька способів налаштування своєї поведінки, включаючи змінні середовища, аргументи командного рядка та файли налаштувань. Цей документ описує різні методи конфігурації та доступні параметри.

## Рівні конфігурації

Налаштування застосовуються в наступному порядку пріоритетності (менші номери перевизначаються більшими):

1.  **Значення за замовчуванням:** Жорстко закодовані значення всередині програми.
2.  **Файл системних стандартів:** Загальносистемні налаштування за замовчуванням.
3.  **Файл користувацьких налаштувань:** Глобальні налаштування для поточного користувача.
4.  **Файл налаштувань проекту:** Налаштування для конкретного проекту.
5.  **Файл системних налаштувань:** Загальносистемні налаштування, що перевизначають усі інші файли.
6.  **Змінні середовища:** Змінні сесії, які можуть завантажуватися з `.env` файлів.
7.  **Аргументи командного рядка:** Значення, передані при запуску CLI.

## Файли налаштувань

Gemini CLI використовує файли JSON для збереження конфігурації. Є чотири основних місця розташування:

- **Файл системних стандартів (System defaults):**
  - **Розташування:** `/etc/gemini-cli/system-defaults.json` (Linux), `C:\ProgramData\gemini-cli\system-defaults.json` (Windows).
  - **Область дії:** Базовий рівень системних налаштувань.
- **Файл користувацьких налаштувань (User settings):**
  - **Розташування:** `~/.gemini/settings.json` (де `~` — ваша домашня директорія).
  - **Область дії:** Застосовується до всіх сесій поточного користувача.
- **Файл налаштувань проекту (Project settings):**
  - **Розташування:** `.gemini/settings.json` у корені вашого проекту.
  - **Область дії:** Застосовується лише під час запуску CLI з цієї директорії.
- **Файл системних налаштувань (System settings):**
  - **Розташування:** `/etc/gemini-cli/settings.json` (Linux), `C:\ProgramData\gemini-cli\settings.json` (Windows).
  - **Область дії:** Має найвищий пріоритет серед усіх файлів налаштувань.

## Змінні середовища

Ви можете керувати поведінкою CLI через змінні середовища (наприклад, у файлі `.env`):

- `GEMINI_CLI_LANG` — мова інтерфейсу (встановіть `ua` для української).
- `GOOGLE_CLOUD_PROJECT` — ваш ID проекту Google Cloud.
- `CLI_TITLE` — кастомний заголовок вікна терміналу.
