# Команди CLI

Gemini CLI підтримує кілька вбудованих команд, які допоможуть вам керувати сесією, налаштовувати інтерфейс та контролювати його поведінку. Ці команди починаються зі слеша (`/`), символу `@` або знаку оклику (`!`).

## Команди через слеш (`/`)

Команди через слеш забезпечують мета-керування самим CLI.

### Вбудовані команди

### `/about`

- **Опис:** Показати інформацію про версію. Надавайте цю інформацію при створенні звернень про помилки.

### `/auth`

- **Опис:** Відкрити діалог, який дозволяє змінити метод авторизації.

### `/bug`

- **Опис:** Повідомити про помилку в Gemini CLI. За замовчуванням звернення створюється в репозиторії GitHub для Gemini CLI. Рядок, який ви введете після `/bug`, стане заголовком звіту. Поведінку `/bug` за замовчуванням можна змінити за допомогою параметра `advanced.bugCommand` у ваших файлах `.gemini/settings.json`.

### `/chat`

- **Опис:** Збереження та відновлення історії розмов для інтерактивного розгалуження стану розмови або відновлення попереднього стану в наступній сесії.
- **Підкоманди:**
  - **`delete <tag>`**
    - **Опис:** Видаляє збережений чекпоінт розмови.
  - **`list`**
    - **Опис:** Показує список доступних тегів для відновлення стану чату.
    - **Примітка:** Ця команда показує лише чати, збережені в поточному проекті. Оскільки історія чату прив'язана до проекту, чати, збережені в інших директоріях проектів, не відображатимуться.
  - **`resume <tag>`**
    - **Опис:** Відновлює розмову з попереднього збереження.
    - **Примітка:** Ви можете відновлювати лише ті чати, які були збережені в поточному проекті.
  - **`save <tag>`**
    - **Опис:** Зберігає поточну історію розмови. Ви повинні додати `<tag>` для ідентифікації стану розмови.

### `/clear`

- **Опис:** Очищає екран терміналу та скидає історію поточної сесії. Це не видаляє збережені чекпоінти.

### `/help`

- **Опис:** Відображає довідку про використання Gemini CLI, включаючи список доступних команд.

### `/model`

- **Опис:** Керування конфігурацією моделі та перегляд квот.
- **Підкоманди:**
  - **`manage`**
    - **Опис:** Відкриває діалог для налаштування параметрів моделі (наприклад, температури).
  - **`set <model-name>`**
    - **Опис:** Швидко перемикає модель на вказану. Додайте `--persist`, щоб зберегти вибір між сесіями.

### `/settings`

- **Опис:** Відкриває вбудований редактор для перегляду та зміни налаштувань Gemini CLI.

### `/theme`

- **Опис:** Відкриває діалог вибору кольорової теми для інтерфейсу CLI.

## Спеціальні команди

### `@` (Контекст файлів)

- **Використання:** `@шлях/до/файлу` або `@папка/`
- **Опис:** Додає вміст вказаного файлу або директорії до контексту вашого наступного запиту. Це дозволяє моделі "бачити" ваш код.

### `!` (Команди оболонки)

- **Використання:** `!<команда>` (наприклад, `!ls -la`)
- **Опис:** Виконує системну команду безпосередньо з промпту Gemini CLI.
