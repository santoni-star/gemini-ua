# Встановлення, запуск та випуски Gemini CLI

Цей документ надає огляд системних вимог Gemini CLI, методів встановлення та типів випусків.

## Рекомендовані системні характеристики

- **Операційна система:**
  - macOS 15+
  - Windows 11 24H2+
  - Ubuntu 20.04+
- **Апаратне забезпечення:**
  - "Звичайне" використання: 4GB+ RAM (короткі сесії, типові завдання та редагування)
  - "Просунуте" використання: 16GB+ RAM (довгі сесії, великі кодові бази, глибокий контекст)
- **Середовище виконання:** Node.js 20.0.0+
- **Оболонка:** Bash, Zsh або PowerShell
- **Підключення до Інтернету обов'язкове**

## Встановлення Gemini CLI (Українська версія)

Оскільки ви використовуєте локалізований форк, рекомендується встановлювати його наступним чином:

### Глобальне встановлення через npm

```bash
npm install -g santoni-star/gemini-ua
```

*Примітка: Якщо під час встановлення виникають помилки прав доступу на Windows, запустіть термінал від імені адміністратора.*

### Встановлення для розробників (з вихідного коду)

Це найнадійніший спосіб для Windows:

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/santoni-star/gemini-ua.git
   cd gemini-ua
   ```
2. Встановіть залежності та зберіть проект:
   ```bash
   npm install
   npm run bundle
   ```
3. Встановіть глобально:
   ```bash
   npm install -g .
   ```

## Запуск Gemini CLI

Для запуску використовуйте команду `gemini-ua`:

```bash
gemini-ua
```

Список основних команд можна знайти у [шпаргалці CLI](/docs/cli/cli-reference.md).

### Запуск без встановлення через npx

```bash
npx santoni-star/gemini-ua
```

## Випуски

Наша українська версія слідує за основними оновленнями оригінального проекту Google, додаючи переклади та виправлення для Windows.

- **Stable (Стабільна):** Перевірена версія з повною локалізацією.
- **Development (Розробка):** Останні зміни прямо з гілки `main`.
