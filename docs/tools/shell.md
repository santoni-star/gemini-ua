# Інструмент оболонки (`run_shell_command`)

Інструмент `run_shell_command` дозволяє моделі Gemini виконувати команди безпосередньо в оболонці вашої системи. Це основний механізм взаємодії агента з вашим середовищем поза простим редагуванням файлів.

## Технічна довідка

На Windows команди виконуються через `powershell.exe -NoProfile -Command`. На інших платформах — через `bash -c`.

### Аргументи

- `command` (рядок, обов'язково): Точна команда оболонки для виконання.
- `description` (рядок, опціонально): Короткий опис, що показується користувачеві для підтвердження.
- `dir_path` (рядок, опціонально): Абсолютний або відносний шлях від кореня проекту, де запускається команда.
- `is_background` (булеве значення, опціонально): Чи слід перевести процес у фоновий режим відразу після запуску.

### Повернені значення

Інструмент повертає об'єкт JSON, що містить:

- `Command`: Виконана команда.
- `Directory`: Шлях виконання.
- `Stdout` / `Stderr`: Потоки виводу.
- `Exit Code`: Код завершення процесу.
- `Background PIDs`: PID будь-яких запущених фонових процесів.

## Конфігурація

Ви можете налаштувати поведінку інструменту `run_shell_command`, змінивши файл `settings.json` або скориставшись командою `/settings` у Gemini CLI.

### Увімкнення інтерактивних команд

Щоб увімкнути інтерактивні команди, встановіть параметр `tools.shell.enableInteractiveShell` у значення `true`. Це активує використання `node-pty` для виконання команд, що дозволяє проводити інтерактивні сесії.
