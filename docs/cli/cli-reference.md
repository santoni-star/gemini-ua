# Шпаргалка Gemini CLI

Ця сторінка містить довідку про часто використовувані команди, опції та параметри Gemini CLI.

## Команди CLI

| Команда                            | Опис                               | Приклад                                             |
| ---------------------------------- | ---------------------------------- | --------------------------------------------------- |
| `gemini-ua`                        | Запустити інтерактивний режим      | `gemini-ua`                                         |
| `gemini-ua "запит"`                | Одноразовий запит, потім вихід     | `gemini-ua "поясни цей проект"`                     |
| `cat file \| gemini-ua`            | Обробити дані через конвеєр (pipe) | `cat logs.txt \| gemini-ua`                         |
| `gemini-ua -i "запит"`             | Виконати та продовжити діалог      | `gemini-ua -i "Яка мета цього проекту?"`            |
| `gemini-ua -r "latest"`            | Продовжити останню сесію           | `gemini-ua -r "latest"`                             |
| `gemini-ua update`                 | Оновити до останньої версії        | `gemini-ua update`                                  |
| `gemini-ua extensions`             | Керування розширеннями             | Див. [Керування розширеннями](#extensions-management)|
| `gemini-ua mcp`                    | Налаштування MCP серверів          | Див. [Керування MCP](#mcp-server-management)        |

## Опції CLI

| Опція                            | Аліас | Тип     | За замовч. | Опис                                                                                             |
| -------------------------------- | ----- | ------- | ---------- | ------------------------------------------------------------------------------------------------ |
| `--debug`                        | `-d`  | boolean | `false`    | Запустити в режимі налагодження з детальним логуванням                                           |
| `--version`                      | `-v`  | -       | -          | Показати версію CLI та вийти                                                                     |
| `--help`                         | `-h`  | -       | -          | Показати довідку                                                                                 |
| `--model`                        | `-m`  | string  | `auto`     | Модель для використання.                                                                         |
| `--prompt-interactive`           | `-i`  | string  | -          | Виконати запит та продовжити в інтерактивному режимі                                             |
| `--sandbox`                      | `-s`  | boolean | `false`    | Запустити в ізольованому середовищі (пісочниці) для безпеки                                      |
| `--approval-mode`                | -     | string  | `default`  | Режим схвалення інструментів: `default`, `auto_edit`, `yolo`                                     |
| `--resume`                       | `-r`  | string  | -          | Відновити попередню сесію. Використовуйте `"latest"` або номер (наприклад, `--resume 5`)         |
| `--list-sessions`                | -     | boolean | -          | Показати список доступних сесій для поточного проекту                                            |
| `--delete-session`               | -     | string  | -          | Видалити сесію за номером (використовуйте `--list-sessions`)                                     |
| `--screen-reader`                | -     | boolean | -          | Увімкнути режим зчитування екрана для доступності                                                |

## Команди всередині CLI (Slash Commands)

Використовуйте ці команди під час інтерактивної сесії:

- `/help` — Показати повну довідку.
- `/settings` — Відкрити редактор налаштувань.
- `/model` — Швидко змінити модель.
- `/clear` — Очистити екран та історію поточної сесії.
- `/about` — Інформація про версію та середовище.
- `/quit` або `/exit` — Вийти з програми.
